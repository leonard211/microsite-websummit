
# Microsite de Evento Tecnológico - Web Summit 2026

## Sobre o Projeto

O Web Summit é uma conferência internacional dedicada à tecnologia, inovação, empreendedorismo e transformação digital, realizada em Lisboa.

Este projeto consiste no desenvolvimento de um microsite informativo e promocional sobre o Web Summit 2026, com o objetivo de apresentar o evento, a sua programação, os oradores e os contactos.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5

## Páginas do Website

O website é composto por quatro páginas HTML:

1. **Início (index.html)** – Apresentação do evento, data, localização e imagem principal.
2. **Programa (programa.html)** – Apresentação das sessões, horários e temas.
3. **Oradores (oradores.html)** – Apresentação dos oradores, fotografias e biografias.
4. **Contacto (contacto.html)** – Formulário de contacto e inscrição.

## Funcionalidades

- Menu de navegação entre as páginas.
- Apresentação de informações sobre o evento.
- Cartões com informações dos oradores.
- Programa com sessões e horários.
- Formulário com validação HTML5.
- Design adaptado a diferentes dispositivos.
